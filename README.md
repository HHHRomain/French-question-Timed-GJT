This is the repository for all the related files to the paper "Justifying a dichotomy of questions in French: evidence from a timed grammaticality judgment task"
The file "Data_raw_80" contains all the raw data for the experiment and the survey.
The file "data_tidy" contains all the files that have been processed in the R software:
1. data_exp (all the datapoints from the experiment)
2. data_exp_remove (after the exclusion based on the correctness rate of fillers)
3. Dichotomy of question in FR (length+freq) (340 sentences used in the experiment)
4. French_Data_survey_80participants (datapoints from the survey of personal background)
